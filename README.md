### 📝 项目简介
本项目是一个基于 **Vite + React + Tailwind CSS** 开发的交互式新闻信息网页。作品以“中国算力”为主题，探索了 AIGC 在传媒领域的工作流应用。

### 🤖 AI 岗位相关亮点 (Interview Highlights)
* **内容生产流：** 网页内的所有新闻素材、摘要及视觉配图均由 **GPT-4 / Midjourney** 辅助生成，实现了高效的内容生产。
* **工程化部署：** 采用 **Git + Vercel CI/CD** 自动化部署方案，具备完整的项目上线与版本管理经验。
* **响应式优化：** 针对移动端进行了视口适配与根字号（Rem/Px）优化，确保多端阅读体验。

### 🛠️ 技术栈
* **前端框架:** React 18 / TypeScript
* **样式处理:** Tailwind CSS
* **构建工具:** Vite
* **部署平台:** Vercel
